# Code of Conduct

PocketFi uses a simple standard: be direct, respectful, and useful.

## Expected Behavior

- Be constructive and specific.
- Assume good intent while still being clear about risks.
- Keep discussion focused on the issue, code, or product behavior.
- Respect user privacy. Do not post personal financial data, receipts, credentials, or private account details.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information without consent.
- Spam, low-effort disruption, or repeated off-topic comments.
- Sharing exploit details publicly before maintainers have a chance to respond.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or restrict repository access when behavior harms the project or its users.

Report conduct concerns through GitHub Issues with the minimum context needed, or request a private contact path if details are sensitive.
